## 1. What we're building

A **product-range brochure** showing the full span of saunas + cold plunge we can offer. Two goals:

1. **Show the range** — New Primitive's own built line, plus a curated set of **Bathing Brands** traditional outdoor saunas we resell (models TBD — Cole sends a separate list).
2. **Interactive matcher (stretch/primary intent):** an interactive form/quiz that suggests products by **budget + space requirements**. NP already runs a live 4-step quiz at newprimitive.co/quiz — mirror its logic (see §6). Design should support both a print/PDF layout AND an interactive version.

**Audience:** the range piece is for prospects choosing across price/space tiers — from a $29k compact solo sauna to a $59k flagship contrast suite, plus lower-cost Bathing Brands options.

## 2. Brand / design language (locked — from existing brochure)

- **Palette:** near-black `#111` dark spreads + warm cream `#F0EDE6` light spreads, alternating. Single accent = **orange** (`~#E8621E`). Sauna heat cue = orange, cold cue = blue (`~#4A90D9`).
- **Type:** big grotesk display (Helvetica/Neue Haas feel) for headlines; **monospace** for labels, section numbers, kickers (e.g. `THE LINEUP`, `$ 04`, `01 / 14`); occasional **serif italic** for one accent word ("*show up*", "*finish*", "*materials*").
- **Signature motifs:** temperature numerals as hero graphics (`212°`, `39°`, `72°`); degree ring `°`; mono footer with page count; per-spread kicker + plate number; product spec grids (2-col label/value pairs).
- **Voice:** terse, mission-led. Thermal bathing as mental-health practice ("A practice, not an exercise." / "Hot. Cold. Repeat." / "Built for the way humans were meant to live."). **No editorial cappers.** Do NOT write new customer-facing brand copy without Cole's pass — reuse the copy captured here.

## 6. Interactive matcher logic (from live quiz — mirror this)

Quiz = **4 steps**: 1. **WHERE** (Backyard · Indoors · Vacation · Commercial) · 2. **WHO** (solo/pair · group 4–6 · crowd 6–8) · 3. **COLD** (under one roof · outdoors · sauna only) · 4. **BUDGET** (entry <$15k · mid $29–48k · premium $48–60k).

**Recommendation logic — BUDGET gates every path (no over-budget recs).** As built in `build/index.html`:

- **Commercial** → *premium:* Commercial ADA (WonderBlock); *mid:* pre-built 212 Designer / 212 Essential (alt: ADA build); *entry:* sauna kit sized to WHO.
- **Indoors** → Custom Indoor Build (alts Nook / 212); entry-budget "why" flags custom pricing starts above kits.
- **Backyard / Vacation** → *entry:* Bathing Brands kit sized to WHO (big→CL12GCP, solo→GL4/EE8G, group→CL7G/GL6); *mid/premium:* if no cold → 212/Nook by size; if cold-outdoor → Primitive Retreat; if cold-under-roof → premium: Thermal Suite Designer, mid: Primitive Retreat (in-budget full loop) or 212 + stand-alone plunge.
- **Kit sizing by WHO:** solo/pair → GL4/EE8G · group → CL7G/GL6 · crowd → CL12GCP (up to 8).

Full matrix (5 WHERE × 3 WHO × 3 COLD × 3 BUDGET) tested — every rec sits within the stated budget tier.
